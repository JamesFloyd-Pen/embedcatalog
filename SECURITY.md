# Security Policy

## Introduction

EmbedCatalog is committed to maintaining the security and integrity of our users data and the platform itself. This security policy outlines how security vulnerabilities should be reported and how they are handled.

For more information about how EmbedCatalog handles data and privacy, please see our [Privacy Notice](https://embedcatalog.com/privacy).

## Supported Versions

This project currently only supports the latest release.

## Reporting a Vulnerability

To report a vulnerability, please send an email with detailed information to hmpllang@gmail.com or open [issue](https://github.com/embedcatalog/embedcatalog/issues/new) on GitHub
